### ✅ Созданы инструменты для работы с данными

**1. `prepare_dataset.py`** - Главный скрипт
- Загружает цены акций с MOEX API
- Читает данные экономистов из Excel
- Добавляет макропоказатели
- Создает готовый датасет для ML

**2. `extract_fundamentals.py`** - Извлечение данных из PDF
- Читает финансовые отчеты
- Извлекает метрики (выручка, EBITDA, прибыль, долг)
- Требует: `pip install pdfplumber`

**3. `analyze_excel.py`** - Анализ Excel файлов
- Показывает структуру данных от экономистов
- Помогает понять формат данных

## Важные замечания

### ⚠️ Проверьте данные экономистов

1. **Выручка Газпрома 2020:** Значение 12.6 млрд сильно отличается от других лет (10000+ млрд). Возможно это квартальные данные или ошибка.

2. **Сургутнефтегаз vs Газпромнефть:** В Excel данные по Сургутнефтегазу (SNGS), но скрипт использует тикер SIBN (Газпромнефть). Это разные компании!

**Решение:** Проверьте вручную Excel файлы и при необходимости скорректируйте.

### ⚠️ Макропоказатели синтетические

Текущие данные (`Oil_Brent_USD`, `USD_RUB`, `MOEX_Index`) - синтетические (для MVP).

**Для production:** Замените на реальные API:
- Нефть: https://www.eia.gov/opendata/
- Валюты: https://www.cbr.ru/development/sxml/
- Индексы: MOEX ISS API

См. подробности в [DATA_PREPARATION_GUIDE.md](DATA_PREPARATION_GUIDE.md)

## FAQ

**Q: Откуда берутся цены акций?**
A: Загружаются с Московской Биржи через бесплатный MOEX ISS API.

**Q: Можно ли добавить другие акции?**
A: Да, отредактируйте `TICKERS` в `prepare_dataset.py` и добавьте соответствующие Excel файлы.

**Q: Почему макроданные синтетические?**
A: Для MVP, чтобы сразу можно было обучить модель. Для production нужно подключить реальные API.

**Q: Как часто обновлять данные?**
A: Рекомендуется раз в день (автоматизация через cron/GitHub Actions).
