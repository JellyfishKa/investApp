# 📊 Руководство по сбору данных для ML модели
## Инструкция для экономистов

> Это руководство поможет собрать качественный датасет для обучения модели прогнозирования цен акций.

---

## 🎯 Цель сбора данных

Собрать **исторические данные** по акциям холдинга Газпром за **минимум 2 года** для обучения модели машинного обучения, которая будет предсказывать цены акций.

---

## 📋 Какие данные нужно собрать

### 1. Основные данные по акциям (ОБЯЗАТЕЛЬНО)

Для каждой из 5 акций нужны **ежедневные данные**:

| Акция | Тикер | Описание |
|-------|-------|----------|
| Газпром | GAZP | Основная акция (головная компания) |
| Газпром (прив.) | GAZP-p | Привилегированные акции |
| Газпром нефть | SIBN | Дочерняя компания |
| Газпром-нефтехим Салават | GCHE | Дочерняя компания |
| Россети Урал | MRKZ | Партнер |

#### Для каждой акции ежедневно:

| Поле | Описание | Пример | Обязательность |
|------|----------|--------|----------------|
| **Дата** | Дата торгов | 2023-11-20 | ✅ ОБЯЗАТЕЛЬНО |
| **Цена открытия (Open)** | Цена на начало торгового дня | 173.45 | ✅ ОБЯЗАТЕЛЬНО |
| **Цена закрытия (Close)** | Цена на конец торгового дня | 173.50 | ✅ ОБЯЗАТЕЛЬНО |
| **Максимум (High)** | Максимальная цена за день | 175.20 | ✅ ОБЯЗАТЕЛЬНО |
| **Минимум (Low)** | Минимальная цена за день | 172.10 | ✅ ОБЯЗАТЕЛЬНО |
| **Объем (Volume)** | Количество проданных акций | 18500000 | ✅ ОБЯЗАТЕЛЬНО |

**Период сбора:** Минимум с 01.01.2022 по текущую дату (лучше больше)

---

### 2. Фундаментальные показатели компаний (ЖЕЛАТЕЛЬНО)

Собирать **ежеквартально** (4 раза в год):

#### Для Газпрома (GAZP):

| Показатель | Описание | Где найти |
|------------|----------|-----------|
| **Выручка** | Квартальная выручка (млрд ₽) | Финансовая отчетность МСФО |
| **EBITDA** | Прибыль до вычета процентов, налогов | Отчетность |
| **Чистая прибыль** | Прибыль после всех расходов | Отчетность |
| **Долг** | Общий долг компании | Баланс |
| **Дивиденды** | Размер выплаченных дивидендов | Решения совета директоров |
| **P/E ratio** | Цена / Прибыль на акцию | Рассчитать или взять с сайта |

**Где взять:**
- Официальный сайт Газпрома (раздел для инвесторов)
- MOEX.com (карточка эмитента)
- Investing.com

### 3. Макроэкономические показатели (ВАЖНО для точности)

Собирать **ежедневно**:

### Вариант 2: CSV файлы (предпочтительный)

Создайте отдельные CSV файлы для каждого тикера:

**Структура папок:**
```
dataset/
├── stocks/
│   ├── GAZP.csv
│   ├── GAZP-p.csv
│   ├── SIBN.csv
│   ├── GCHE.csv
│   └── MRKZ.csv
├── fundamentals/
│   └── GAZP_fundamentals.csv
└── macro/
    └── macro_indicators.csv
```

**Формат CSV (пример GAZP.csv):**
```csv
Date,Open,Close,High,Low,Volume
2022-01-03,325.50,328.10,330.00,324.50,15000000
2022-01-04,328.00,326.50,329.00,325.00,14500000
2022-01-05,326.50,327.80,328.50,326.00,13800000
```

**Важно:**
- Используйте запятую `,` как разделитель
- Даты в формате `YYYY-MM-DD`
- Числа с точкой `.` (не запятая!)
- Кодировка UTF-8

## 🔍 Где взять данные

### Официальные источники (БЕСПЛАТНО):

#### 1. **MOEX API** (Московская Биржа)
**Сайт:** https://www.moex.com/a2193

**Как использовать:**
1. Перейдите по ссылке
2. Выберите "ISS Reference"
3. Найдите endpoint: `/iss/history/engines/stock/markets/shares/boards/TQBR/securities/{TICKER}.json`

**Пример запроса для Газпрома:**
```
https://iss.moex.com/iss/history/engines/stock/markets/shares/boards/TQBR/securities/GAZP.json?from=2022-01-01&till=2023-12-31
```

**Можно скачать CSV:**
```
https://iss.moex.com/iss/history/engines/stock/markets/shares/boards/TQBR/securities/GAZP.csv?from=2022-01-01&till=2023-12-31
```

---

#### 2. **Finam Export**
**Сайт:** https://www.finam.ru/profile/moex-akcii/gazprom/export/

**Как скачать:**
1. Выберите тикер (например, Газпром)
2. Выберите период (От: 01.01.2022, До: текущая дата)
3. Выберите таймфрейм: "Дневные данные"
4. Формат файла: CSV
5. Нажмите "Получить файл"

**Плюсы:** Очень удобно, сразу в нужном формате

---

#### 3. **Investing.com**
**Сайт:** https://ru.investing.com/

**Как скачать:**
1. Найдите акцию (например, "Газпром")
2. Перейдите на вкладку "Исторические данные"
3. Выберите период
4. Нажмите "Скачать данные" → CSV файл

**Для макропоказателей:**
- Нефть: https://ru.investing.com/commodities/brent-oil-historical-data
- USD/RUB: https://ru.investing.com/currencies/usd-rub-historical-data

---

#### 4. **ЦБ РФ (для курсов валют)**
**Сайт:** https://www.cbr.ru/development/sxml/

**XML API для курсов:**
```
https://www.cbr.ru/scripts/XML_daily.asp?date_req=20/11/2023
```

---

#### 5. **Python библиотеки (для программистов)**

```python

pip install yfinance moexalgo pandas
```

## 🚨 Частые ошибки и как их избежать

### ❌ Ошибка 1: Разные форматы дат
**Проблема:** В одном файле `20.11.2023`, в другом `2023-11-20`
**Решение:** Используйте ТОЛЬКО формат `YYYY-MM-DD` (2023-11-20)

### ❌ Ошибка 2: Запятая вместо точки
**Проблема:** Цена записана как `173,50` вместо `173.50`
**Решение:** В Excel: Формат ячеек → Число → Использовать точку

### ❌ Ошибка 3: Пропуски в данных
**Проблема:** Пропущены дни, когда биржа не работала
**Решение:** Это нормально! Выходные и праздники пропускаем

### ❌ Ошибка 4: Разная длина файлов
**Проблема:** Для GAZP данные с 2022, для SIBN с 2023
**Решение:** Все файлы должны начинаться с одной даты (01.01.2022)

### ❌ Ошибка 5: Нулевые объемы
**Проблема:** В некоторые дни Volume = 0
**Решение:** Это означает, что торгов не было, можно оставить
