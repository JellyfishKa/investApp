# Тестирование Invest MRSU Backend

Эта папка содержит скрипты для отладки и тестирования backend компонентов.

## 🧪 Доступные тесты

### 1. test_ml.py - Тестирование ML компонентов

Проверяет работу ML моделей **без необходимости запуска базы данных**.

```bash
cd test
python test_ml.py
```

**Что тестируется:**
- ✓ Препроцессор (технические индикаторы, нормализация)
- ✓ LSTM модель (архитектура, предсказания)
- ✓ MOEX collector (сбор данных)
- ✓ CSV importer (импорт фундаментальных данных)

**Требования:**
- Python 3.11+
- `pip install -r ../backend/requirements.txt`

---

### 2. test_api.py - Тестирование API

Проверяет работу FastAPI endpoints.

```bash
# Сначала запустите backend:
cd ../backend
python main.py

# В другом терминале:
cd ../test
python test_api.py
```

**Что тестируется:**
- ✓ Health check
- ✓ Predict endpoint (прогнозирование)
- ✓ History endpoint (исторические данные)
- ✓ Batch predictions (множественные прогнозы)

**Требования:**
- Запущенный backend (`python main.py`)
- База данных с данными

---

## 📋 Быстрый старт для отладки

### Вариант A: Тестирование без БД

```bash
# 1. Установить зависимости
cd backend
pip install -r requirements.txt

# 2. Запустить ML тесты
cd ../test
python test_ml.py
```

### Вариант B: Полное тестирование

```bash
# 1. Запустить базу данных
cd backend
docker-compose up -d db

# 2. Загрузить данные (опционально)
curl -X POST http://localhost:8000/admin/update_moex

# 3. Запустить backend
python main.py

# 4. В другом терминале - тесты API
cd ../test
python test_api.py
```

## 🔧 Отладка проблем

### Проблема: "Module not found"

```bash
# Убедитесь, что установлены зависимости:
cd backend
pip install -r requirements.txt
```

### Проблема: "Connection refused" в test_api.py

```bash
# Убедитесь, что backend запущен:
cd backend
python main.py
# Должно показать: "Uvicorn running on http://0.0.0.0:8000"
```

### Проблема: "Model not found" в predict

```bash
# Необходимо обучить модели:
cd backend
python ml/trainer.py
```

## 💡 Полезные команды

```bash
# Проверить, запущен ли backend
curl http://localhost:8000/

# Получить прогноз вручную
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"ticker":"GAZP","period":"month"}'

# Обновить данные с MOEX
curl -X POST http://localhost:8000/admin/update_moex
```
