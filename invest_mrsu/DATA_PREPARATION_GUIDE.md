# Руководство по подготовке данных для ML модели
## Invest MRSU - Работа с реальными данными

> Это руководство описывает, как подготовить датасет для обучения ML модели, используя реальные данные от экономистов и MOEX API

---

## Обзор созданных инструментов

### 1. `prepare_dataset.py` - Главный скрипт подготовки данных

**Что делает:**
- Загружает исторические цены акций с Московской Биржи (MOEX API)
- Читает данные от экономистов из Excel файлов
- Объединяет с макроэкономическими показателями
- Добавляет технические индикаторы (MA7, MA30, Returns)
- Сохраняет готовый датасет в CSV для ML модели

**Использование:**
```bash
cd invest_mrsu
python prepare_dataset.py
```

**Результат:**
```
dataset/
├── stocks/
│   ├── GAZP.csv      # Газпром: 1445 записей (2020-2024)
│   └── SIBN.csv      # Газпромнефть: 1443 записей (2020-2024)
└── macro/
    └── macro_indicators.csv  # Макропоказатели
```

---

### 2. `extract_fundamentals.py` - Извлечение данных из PDF отчетов

**Что делает:**
- Читает PDF финансовые отчеты Газпрома (2020-2024)
- Извлекает ключевые метрики: выручка, EBITDA, чистая прибыль, долг, дивиденды
- Сохраняет в CSV для использования в ML модели

**Требования:**
```bash
pip install pdfplumber PyPDF2
```

**Использование:**
```bash
cd invest_mrsu
python extract_fundamentals.py
```

**Результат:**
```
dataset/fundamentals/
└── GAZP_fundamentals.csv  # Фундаментальные данные по годам
```

---

### 3. `analyze_excel.py` - Анализ данных от экономистов

**Что делает:**
- Анализирует структуру Excel файлов, подготовленных экономистами
- Показывает статистику: количество строк, колонок, пропусков
- Помогает понять формат данных для адаптации скриптов

**Использование:**
```bash
cd investApp  # корневая директория
python analyze_excel.py
```

## Структура подготовленного датасета

### Файл: `dataset/stocks/GAZP.csv`

**Колонки (16 фичей):**

| Колонка | Тип | Описание | Источник |
|---------|-----|----------|----------|
| `Date` | datetime | Дата торгового дня | MOEX API |
| `Open` | float | Цена открытия (руб.) | MOEX API |
| `Close` | float | Цена закрытия (руб.) | MOEX API |
| `High` | float | Максимальная цена (руб.) | MOEX API |
| `Low` | float | Минимальная цена (руб.) | MOEX API |
| `Volume` | int | Объем торгов (шт.) | MOEX API |
| `Year` | int | Год (для джойна) | Вычислено |
| `Revenue_bn` | float | Выручка компании (млрд руб.) | Экономисты |
| `Oil_Brent_USD` | float | Цена нефти Brent ($/барр.) | Синтетика* |
| `USD_RUB` | float | Курс доллара | Синтетика* |
| `EUR_RUB` | float | Курс евро | Синтетика* |
| `CB_Rate` | float | Ключевая ставка ЦБ (%) | Константа |
| `MOEX_Index` | float | Индекс МосБиржи | Синтетика* |
| `MA_7` | float | Скользящая средняя 7 дней | Вычислено |
| `MA_30` | float | Скользящая средняя 30 дней | Вычислено |
| `Returns` | float | Дневная доходность (%) | Вычислено |

**⚠️ Примечание:** *Синтетика - данные для MVP, нужно заменить на реальные API

## Анализ данных от экономистов

### Сводка данных по Газпрому.xlsx

**Найденные данные:**
```
2020: Выручка = 12.6 млрд руб.
2021: Выручка = 10241.4 млрд руб.
2022: Выручка = 11673.9 млрд руб.
2023: Выручка = 8541.8 млрд руб.
2024: Выручка = 10714.7 млрд руб.
```

**⚠️ Проблема:** Выручка 2020 года (12.6 млрд) значительно отличается от других лет.
**Причина:** Возможно, это не годовые, а квартальные данные, или ошибка парсинга Excel.
**Решение:** Проверить вручную Excel файл и при необходимости скорректировать данные.

### Сводка_данных_по_Сургутнефтегаз_2020_2024_год.xlsx

**Найденные данные:**
```
2020: Выручка = 0.7 млрд руб.
2021: Выручка = 0.8 млрд руб.
2022: Выручка = 0.8 млрд руб.
2023: Выручка = 0.8 млрд руб.
2024: Выручка = 0.9 млрд руб.
```

**⚠️ Примечание:** Сургутнефтегаз (SNGS) ≠ Газпромнефть (SIBN).
В скрипте используется тикер SIBN (Газпромнефть), но Excel содержит данные по Сургутнефтегазу.
**Решение:** Либо изменить тикер на SNGS, либо получить правильные данные по SIBN.

## Как улучшить датасет

### 1. Добавить реальные макропоказатели

**Текущая проблема:** Используются синтетические данные (Oil_Brent_USD, USD_RUB, etc.)

**Решение:**

```python

pip install yfinance fredapi

# Пример для нефти Brent
import yfinance as yf
brent = yf.download("BZ=F", start="2020-01-01")  # Brent Crude Oil

# Пример для валют (ЦБ РФ)
import requests
url = "https://www.cbr.ru/scripts/XML_daily.asp?date_req=20/11/2024"
response = requests.get(url)
# Парсить XML...
```

**API источники:**
- Нефть Brent: https://www.eia.gov/opendata/ (бесплатно)
- Валюты: https://www.cbr.ru/development/sxml/ (бесплатно)
- Индексы MOEX: https://iss.moex.com/iss/history/engines/stock/markets/index/

## Частые проблемы и решения

### Проблема 1: "Данные от экономистов не парсятся"

**Причина:** Excel файл имеет сложную структуру (merged cells, headers)

**Решение:**
1. Открыть Excel вручную
2. Скопировать данные в новый лист в простом формате
3. Сохранить как CSV
4. Использовать CSV вместо Excel

### Проблема 2: "MOEX API возвращает пустой результат"

**Причина:** Неверный тикер или период

**Решение:**
```python
# Проверить доступные тикеры
url = "https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities.json"
response = requests.get(url)
print(response.json()['securities']['data'][:10])
```

### Проблема 3: "Много пропусков в выручке (Revenue_bn)"

**Причина:** Фундаментальные данные доступны только по годам, а датасет дневной

**Решение:** Это нормально. Модель будет использовать годовую выручку для всех дней этого года.
