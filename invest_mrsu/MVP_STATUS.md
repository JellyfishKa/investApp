### 🛠 Технологический стек

**Frontend:**
- Flutter 3.9.2
- Provider (state management)
- fl_chart (графики)
- intl (форматирование)

**Архитектура:**
- Модели данных (Stock, Portfolio, Dividend, Prediction, Task)
- Providers для управления состоянием
- Mock данные для демонстрации
- Material Design 3

## 🐛 Известные ограничения MVP

- Mock авторизация (принимает любые данные)
- Синтетические данные вместо реальных котировок
- Прогнозы не основаны на реальной ML модели
- Нет сохранения данных между сеансами
- Нет реальных уведомлений
