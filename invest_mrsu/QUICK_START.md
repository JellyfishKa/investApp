## Первый запуск

1. **Откройте приложение**
2. **Зарегистрируйтесь:**
   - Email: любой (например: `test@mail.com`)
   - Пароль: минимум 6 символов (например: `123456`)
3. **Нажмите "Зарегистрироваться"**

## 🎮 Как пользоваться приложением

### Главный экран (Dashboard)

**Что здесь есть:**
- 💰 **Общий баланс**: ваш виртуальный капитал (начальные 100,000₽)
- 💵 **Свободные средства**: деньги для покупки акций
- 📊 **В акциях**: текущая стоимость вашего портфеля
- 📈 **Прибыль/убыток**: насколько выросли ваши инвестиции

**Быстрые действия:**
- Зеленая кнопка "Купить" → переход к списку акций
- Красная кнопка "Продать" → переход к портфелю

### 📊 Вкладка "Акции"

Здесь можно увидеть все доступные акции холдинга Газпром:
- **GAZP** - Газпром (головная компания) 🏭
- **GAZP-p** - Газпром привилегированные 🏭
- **SIBN** - Газпром нефть ⛽
- **GCHE** - Газпром-нефтехим ⚗️
- **MRKZ** - Россети Урал ⚡

**Как купить акцию:**
1. Нажмите на любую акцию
2. Изучите информацию (график, прогнозы, дивиденды)
3. Нажмите кнопку "Купить" внизу
4. Введите количество
5. Подтвердите покупку

### 💼 Вкладка "Портфель"

**Активы:**
- Все купленные акции
- Текущая стоимость
- Прибыль/убыток по каждой позиции
- Средняя цена покупки

**История:**
- Все совершенные транзакции
- Дата и время сделки
- Количество и цена

**Как продать акцию:**
1. Нажмите на акцию в портфеле
2. Откроется детальный экран
3. Нажмите кнопку "Продать"
4. Введите количество
5. Подтвердите продажу

### 🏆 Вкладка "Задания"

Выполняйте задания и получайте бонусы!

**Доступные задания:**
1. ✅ **Добро пожаловать** - 100₽ (автоматически)
2. 💰 **Первые шаги инвестора** - 500₽ (купите акцию)
3. 📊 **Аналитик** - 300₽ (посмотрите прогнозы по 3 компаниям)
4. ⏳ **Долгосрочный инвестор** - 1000₽ (держите акции 7 дней)
5. 📅 **Постоянный пользователь** - 200₽ (ежедневный вход)

**Как получить награду:**
1. Выполните задание (прогресс отображается)
2. Когда задание завершено, появится зеленая кнопка
3. Нажмите "Получить награду"
4. Бонус будет добавлен на баланс!

## 📱 Детальный экран акции

### Вкладка "График"
- Выберите период: 1W, 1M, 3M, 1Y, ALL
- Интерактивный график цены
- Статистика: Мин, Макс, Средняя цена

### Вкладка "Прогнозы"
**Прогнозы от ML модели:**
- 📅 **Неделя**: краткосрочный прогноз
- 📅 **Месяц**: среднесрочный прогноз
- 📅 **Год**: долгосрочный прогноз

Для каждого прогноза показывается:
- Ожидаемая цена
- Процент изменения
- **Потенциальная прибыль** (если у вас есть эти акции)

### Вкладка "Дивиденды"
- 💰 **Ваши дивиденды**: общая сумма (если есть акции)
- ✅ **Выплачено**: прошлые выплаты
- 📅 **Ожидается**: подтвержденные будущие выплаты
- 🔮 **Прогноз**: предсказанные дивиденды

## 💡 Полезные советы

1. **Начните с малого**: купите 1-2 акции для теста
2. **Изучайте прогнозы**: смотрите ML предсказания перед покупкой
3. **Следите за дивидендами**: они дают дополнительный доход
4. **Выполняйте задания**: это бесплатные деньги!
5. **Диверсифицируйте**: не вкладывайте все в одну акцию

## ❓ FAQ

**В: Почему я не могу купить акцию?**
О: Проверьте баланс. Стоимость покупки = цена × количество

**В: Как продать все акции?**
О: В диалоге продажи введите количество = количеству в портфеле

**В: Когда обновляются цены?**
О: В MVP цены статичные (синтетические данные)

**В: Где сохраняются мои данные?**
О: В MVP данные хранятся только в сессии (исчезают при закрытии)

**В: Как получить больше денег?**
О: Выполняйте задания и получайте бонусы!
