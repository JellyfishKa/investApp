# ML-модель (LSTM)

Прогнозирование цен акций с помощью рекуррентной нейросети LSTM (Long Short-Term Memory).

## Архитектура

```
Input: (60 дней, 17 признаков)
    │
    ▼
LSTM (128 юнитов, return_sequences=True)
    │
Dropout (0.2)
    │
    ▼
LSTM (64 юнита)
    │
Dropout (0.2)
    │
    ▼
Dense (32 юнита, ReLU)
    │
Dropout (0.1)
    │
    ▼
Dense (1 юнит) — предсказанная цена
```

- **Оптимизатор:** Adam (learning rate = 0.001)
- **Функция потерь:** Huber Loss (устойчива к выбросам)
- **Метрики:** MAE, MSE

## Признаки (17 штук)

Модель получает на вход последовательность из 60 торговых дней, каждый описан 17 числовыми признаками:

| № | Признак | Описание |
|---|---|---|
| 1 | open | Цена открытия |
| 2 | high | Максимальная цена за день |
| 3 | low | Минимальная цена за день |
| 4 | close | Цена закрытия (целевая переменная) |
| 5 | volume | Объём торгов |
| 6 | ma_7 | Скользящая средняя за 7 дней |
| 7 | ma_30 | Скользящая средняя за 30 дней |
| 8 | ma_90 | Скользящая средняя за 90 дней |
| 9 | rsi | Relative Strength Index (14 дней) |
| 10 | macd | Moving Average Convergence Divergence |
| 11 | macd_signal | Сигнальная линия MACD |
| 12 | bb_upper | Верхняя полоса Боллинджера |
| 13 | bb_lower | Нижняя полоса Боллинджера |
| 14 | momentum_1d | Изменение цены за 1 день (%) |
| 15 | momentum_7d | Изменение цены за 7 дней (%) |
| 16 | volume_change | Изменение объёма за 1 день (%) |
| 17 | price_range | (high - low) / close |

Все признаки нормализуются MinMaxScaler в диапазон [0, 1].

## Процесс обучения

### Подготовка данных

1. Загрузка котировок из PostgreSQL (таблица `stock_data`)
2. Расчёт технических индикаторов (MA, RSI, MACD, Bollinger Bands, Momentum)
3. Заполнение пропусков (backfill)
4. Нормализация MinMaxScaler
5. Формирование последовательностей:
   - Вход: 60 дней × 17 признаков
   - Выход: цена закрытия через N дней (по умолчанию 30)
6. Разбиение: 70% train, 15% validation, 15% test

### Обучение

Запуск:
```bash
cd invest_mrsu/backend
python ml/trainer.py
```

Параметры по умолчанию:
- Последовательность: 60 дней
- Горизонт прогноза: 30 дней
- Эпохи: до 100 (с EarlyStopping, patience=15)
- Батч: 32
- Уменьшение LR при плато (factor=0.5, patience=7)

Модели обучаются последовательно для каждого тикера из списка: GAZP, GAZP-p, SIBN, GCHE, MRKZ.

### Результаты

После обучения для каждого тикера сохраняются:
- `models/{TICKER}_model.keras` — обученная модель
- `models/{TICKER}_preprocessor.pkl` — объект препроцессора (для обратной нормализации)
- `models/{TICKER}_history.pkl` — история обучения
- `models/training_summary.json` — сводка метрик по всем тикерам

### Метрики оценки

| Метрика | Описание |
|---|---|
| MAE | Средняя абсолютная ошибка |
| MSE | Среднеквадратичная ошибка |
| RMSE | Корень из MSE |
| MAPE | Средняя абсолютная процентная ошибка |
| R² | Коэффициент детерминации |

## Прогнозирование

При запросе прогноза через API:

1. Загружается обученная модель с диска
2. Берутся последние 60 дней из базы данных
3. Рассчитываются технические индикаторы
4. Данные нормализуются тем же скейлером, что при обучении
5. Модель выдаёт нормализованное значение
6. Обратная нормализация → реальная цена
7. Доверительный интервал: ±10% от прогноза (упрощённый)

## Ограничения

- Модель не учитывает фундаментальные данные (выручка, прибыль) — только ценовые паттерны
- Макроэкономические факторы (нефть, курс рубля) не включены в признаки
- Доверительный интервал фиксирован (±10%), а не рассчитан из неопределённости модели
- Для полноценной оценки нужно минимум 2-3 года дневных данных (500+ торговых дней)
- Модель обучается offline, нет автоматического переобучения при поступлении новых данных
- Одна модель на тикер, нет ансамблирования
