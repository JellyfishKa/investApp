# Теоретические планы развития проекта

Эта папка содержит **концептуальные планы** дальнейшего развития Invest MRSU, разработанные на стадии проектирования. Они описывают, каким приложение может стать при полной реализации задуманного.

Важно: это не техническое задание и не обязательство. Это видение продукта, к которому можно стремиться. Конкретные решения принимаются по мере продвижения.

## Содержание

1. **[Концепция «Пре-Брокер»](concept-prebroker.md)** — расширенная концепция приложения как полноценного обучающего тренажёра для начинающих инвесторов. Включает:
   - Мультифакторная LSTM-модель (цена, сентимент, геополитика, киты)
   - Генератор исторических сценариев (санкции, кризисы, дефолты)
   - Система геймификации (8 уровней, достижения, XP)
   - Учебная программа на 4 месяца (64 урока)

2. **[План реализации](implementation-plan.md)** — детальный план разработки в формате 4-месячного акселератора. Включает:
   - Ответы на 35 ключевых вопросов по архитектуре и бизнесу
   - Методология (Kanban + спринты)
   - Расчёт бюджета MVP (~27 800 руб.)
   - Состав команды (5 человек, 75-100 ч/нед)
   - Диаграмма Ганта на 17 недель
   - Метрики успеха и управление рисками

3. **[Дорожная карта](roadmap.md)** — выжимка из планов: что делать в каком порядке.

## Как пользоваться этими документами

- Читать как ориентир, а не как инструкцию
- Выбирать конкретные идеи для реализации в текущем спринте
- Использовать для презентаций и защит (видение продукта)
- Сопоставлять с [текущим состоянием проекта](../improvements.md) — что уже сделано, что предстоит
