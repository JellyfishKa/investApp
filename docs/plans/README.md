# Архив планов развития

Эта папка хранит исторические и концептуальные планы проекта.  
Документы полезны как контекст, но не являются главным источником текущей стратегии.

## Содержание

1. **[Концепция «Пре-Брокер»](concept-prebroker.md)** — ранняя расширенная концепция приложения как обучающего тренажёра для начинающих инвесторов. Включает:
   - Мультифакторная LSTM-модель (цена, сентимент, геополитика, киты)
   - Генератор исторических сценариев (санкции, кризисы, дефолты)
   - Система геймификации (8 уровней, достижения, XP)
   - Учебная программа на 4 месяца (64 урока)

2. **[План реализации](implementation-plan.md)** — ранний детальный план разработки в формате 4-месячного акселератора. Включает:
   - Ответы на 35 ключевых вопросов по архитектуре и бизнесу
   - Методология (Kanban + спринты)
   - Расчёт бюджета MVP (~27 800 руб.)
   - Состав команды (5 человек, 75-100 ч/нед)
   - Диаграмма Ганта на 17 недель
   - Метрики успеха и управление рисками

3. **[Дорожная карта](roadmap.md)** — укрупнённая выжимка из ранних планов.

## Как пользоваться этим архивом

- использовать как исторический контекст;
- брать из него идеи, но проверять через текущую стратегию;
- не воспринимать как обязательный roadmap.
