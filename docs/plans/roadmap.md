# Дорожная карта

Сводная карта развития проекта Invest MRSU — от текущего состояния до целевого продукта.

---

## Где мы сейчас

Готово:
- Flutter-приложение с 4 вкладками (дашборд, акции, портфель, задачи) — на мок-данных
- Backend API на FastAPI (5 эндпоинтов: health, predict, history, upload_csv, update_moex)
- LSTM-модель (архитектура и пайплайн обучения)
- Сбор данных с MOEX ISS API
- Docker-инфраструктура (PostgreSQL + приложение)
- Базовые тесты

Не готово:
- Реальная связка Flutter ↔ Backend (приложение на mock-данных)
- Аутентификация
- Автоматическое обновление данных
- Обучающий контент (уроки, тесты)
- Геймификация
- Сценарии

---

## Ближайшие шаги (что можно сделать уже сейчас)

1. **Подключить Flutter к backend** — заменить мок-данные на API-вызовы
2. **Добавить JWT-аутентификацию** — защитить API, связать с LoginScreen
3. **Настроить cron-обновление** — APScheduler для ежедневного сбора данных с MOEX
4. **Обучить LSTM на реальных данных** — загрузить котировки, запустить trainer.py
5. **Улучшить доверительный интервал** — Monte Carlo Dropout или калибровка по тесту
