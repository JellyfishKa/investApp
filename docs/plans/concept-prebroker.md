# Концепция «Пре-Брокер»

Расширенное видение приложения Invest MRSU как полноценного обучающего тренажёра для начинающих инвесторов на российском фондовом рынке.

---

## Суть идеи

Пользователь проходит путь от базовых понятий (что такое акция) до симуляции реальной торговли в условиях кризисов, санкций и рыночных манипуляций. Всё это — без риска для реальных денег, с системой уровней и наград.

Приложение учит не тому, «какую акцию купить», а тому, как принимать решения в условиях неопределённости.

## Расширенная модель машинного обучения

Текущая LSTM-модель использует 17 ценовых признаков. В расширенной версии предполагается мультифакторный подход:

### Входные признаки

| Группа | Признаки |
|---|---|
| Ценовые | OHLCV, скользящие средние, RSI, MACD, Bollinger Bands |
| Объёмные | Объём торгов, дисбаланс bid/ask, крупные сделки |
| Макроэкономика | Ключевая ставка ЦБ, курс USD/RUB, цена нефти Brent |
| Сентимент | Тональность новостей (NLP-модель, score от -1 до +1) |
| Геополитика | GDELT conflict index, флаги санкций |
| Календарные | День недели, месяц, предпраздничные дни |
| Специальные | Флаги исторических кризисов (2008, 2014, 2020, 2022) |

### Несколько моделей

| Модель | Задача | Выход |
|---|---|---|
| Price Predictor | Прогноз цены на 1/5/20 дней | Число (цена) |
| Crisis Detector | Обнаружение кризисного события | Класс (норма / предупреждение / кризис) |
| Whale Detector | Детекция крупных игроков | Класс (покупка кита / продажа кита / нет) |
| Sentiment Analyzer | Тональность новостей → влияние на цену | Score от -1 до +1 |

### Дополнительные источники данных

| Источник | Что даёт | Доступ |
|---|---|---|
| MOEX ISS | Котировки, история торгов, индексы | Бесплатно |
| Tinkoff Invest API | Свечи, стакан, портфель | Бесплатно (нужен токен) |
| Finam Export | Историческая выгрузка свечей | Бесплатно |
| CBR API | Курсы валют, ставка, макростатистика | Бесплатно |
| GDELT Project | Геополитические события, тональность новостей | Бесплатно |
| Росстат | Социально-экономические показатели | Бесплатно |
| Kaggle | Исторические котировки, новостные корпуса | Бесплатно |

## Генератор сценариев

Ключевая обучающая механика — прохождение исторических и синтетических сценариев.

### Типы сценариев

| Сценарий | Описание | Сложность |
|---|---|---|
| Обычный рынок | Спокойная торговля, базовые навыки | Низкая |
| Бычий рост | Быстрый рост, важно не переоценить | Средняя |
| Санкции 2014 | Крымский кризис, обвал рубля | Высокая |
| Обвал нефти 2020 | Нефть по $25, пандемия | Высокая |
| Дефолт 1998 | Полный крах рынка | Максимальная |
| Дивидендный гэп | Падение после отсечки | Средняя |
| Кит двигает рынок | Крупный игрок входит/выходит | Высокая |
| Решение ЦБ по ставке | Неожиданное повышение/снижение | Средняя |

### Цепочки событий (комбинированные)

Реалистичные последовательности:
- Падение нефти → девальвация рубля → повышение ставки ЦБ
- Санкции → отток капитала → каскад маржин-коллов
- Геополитическая эскалация → паника → кит скупает на дне
- Снятие санкций → приток инвестиций → бычий рынок

### Матрица влияния факторов

Каждое событие влияет на секторы с разной силой. Пример:

| Событие | Нефтегаз | Банки | IT | Золотодобытчики |
|---|---|---|---|---|
| Новые санкции | -15% | -25% | -10% | +5% |
| Обвал нефти | -30% | -10% | -3% | 0% |
| Повышение ставки | 0% | +8% | -15% | -3% |
| Дефолт | -50% | -70% | -40% | -20% |

## Торговый движок (симулятор)

Серверный движок симуляции:
- Виртуальный портфель с начальным балансом 1 000 000 руб.
- Пошаговая торговля (1 шаг = 1 торговый день)
- На каждом шаге: рыночные данные + события + LSTM-подсказки
- Типы ордеров: рыночный, лимитный, стоп-лосс, тейк-профит
- Комиссии и слиппедж (как у настоящего брокера)
- Оценка результатов: доходность, Sharpe ratio, максимальная просадка, качество решений

## Система геймификации

### 8 уровней пользователя

| Уровень | Название | XP |
|---|---|---|
| 1 | Наблюдатель | 0–500 |
| 2 | Стажёр | 500–1 500 |
| 3 | Младший аналитик | 1 500–3 500 |
| 4 | Аналитик | 3 500–7 000 |
| 5 | Трейдер | 7 000–12 000 |
| 6 | Старший трейдер | 12 000–20 000 |
| 7 | Портфельный управляющий | 20 000–35 000 |
| 8 | Мастер рынка | 35 000+ |

### Как зарабатывать XP

| Действие | XP |
|---|---|
| Урок пройден | +50 |
| Тест на отлично (100%) | +100 |
| Сценарий пройден | +200–500 |
| Серия (7 дней подряд) | +150 |
| Достижение (первая прибыль, пережил дефолт и т.д.) | +300 |
| Челлендж (обыграй индекс MOEX за месяц) | +500 |
| Пригласил друга | +100 |

### Типы заданий

| Тип | Описание | XP |
|---|---|---|
| Тест после теории | Ответить на вопросы | 30–100 |
| Чтение графика | Определить паттерн | 50–250 |
| Торговля в сценарии | Пережить исторический кризис | 200–800 |
| Управление рисками | Расставить стоп-лоссы | 100–350 |
| Сборка портфеля | Подобрать активы под профиль риска | 250–600 |
| Выживание в кризис | Минимизировать потери | 500–1 000 |

## Учебная программа (4 месяца)

### Месяц 1: Основы

- Неделя 1: Что такое фондовый рынок, участники, типы бумаг, Московская биржа
- Неделя 2: Виды графиков, таймфреймы, объём торгов, тренды, уровни поддержки
- Неделя 3: Финансовая отчётность, мультипликаторы (P/E, P/B, EV/EBITDA), дивиденды
- Неделя 4: Типы ордеров, комиссии, налоги, ИИС, первые сделки в симуляторе

### Месяц 2: Углублённый анализ

- Неделя 5: Скользящие средние, RSI, MACD, Bollinger Bands
- Неделя 6: Риск-менеджмент, стоп-лосс, размер позиции, диверсификация
- Неделя 7: Макроэкономика (ставка ЦБ, инфляция, курс рубля, нефть)
- Неделя 8: Секторальный анализ (нефтегаз, банки, металлы, IT)

### Месяц 3: Продвинутые сценарии

- Неделя 9: Геополитика и рынок (санкции 2014, 2022)
- Неделя 10: «Киты» и рыночные манипуляции
- Неделя 11: Кризисы и дефолты (1998, 2008, 2020)
- Неделя 12: Портфельное управление (теория Марковица, ребалансировка)

### Месяц 4: Мастерство

- Неделя 13: Фьючерсы, опционы, маржинальная торговля, хеджирование
- Неделя 14: Психология трейдинга, когнитивные искажения, торговый дневник
- Неделя 15: Комплексные LSTM-сценарии (год на рынке, стагфляция, ловушки)
- Неделя 16: Финальный экзамен (100 вопросов + 3-месячная симуляция)

Итого: 64 урока, 32 теста, 15 сценариев.

## Инфраструктура (целевая)

Docker Compose с сервисами:
- **backend** — FastAPI-приложение
- **ml-worker** — Celery-воркер для ML-задач (опционально: GPU)
- **db** — PostgreSQL
- **redis** — кэш и очередь задач
- **nginx** — обратный прокси
- **data-fetcher** — cron-задача по загрузке данных с MOEX
