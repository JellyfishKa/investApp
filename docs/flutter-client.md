# Flutter-клиент

Мобильное приложение на Flutter с Material 3 дизайном. Поддерживает Android и Windows (теоретически — iOS, macOS, Linux, Web, но не тестировалось).

## Запуск

```bash
cd invest_mrsu
flutter pub get
flutter run
```

Приложение работает на мок-данных без необходимости запуска backend.

## Зависимости

| Пакет | Версия | Назначение |
|---|---|---|
| provider | ^6.1.2 | Управление состоянием |
| fl_chart | ^0.69.0 | Графики цен |
| intl | ^0.19.0 | Форматирование дат и чисел (локаль ru_RU) |
| shared_preferences | ^2.3.3 | Локальное хранение настроек |
| http | ^1.2.0 | HTTP-запросы к backend |

SDK: Dart ^3.9.2.

## Структура приложения

### Модели (`lib/models/`)

| Файл | Описание |
|---|---|
| `stock.dart` | Акция: тикер, название, цена, изменение, объём |
| `dividend.dart` | Дивиденд: дата выплаты, сумма на акцию, статус |
| `price_history.dart` | Точка на графике: дата + цена |
| `prediction.dart` | Прогноз ML-модели: цена, доверительный интервал, точность |
| `portfolio.dart` | Портфель: баланс, позиции, общая стоимость |
| `transaction.dart` | Сделка: покупка или продажа, количество, цена |
| `task.dart` | Учебное задание: заголовок, описание, статус выполнения |

### Провайдеры (`lib/providers/`)

Управление состоянием через `ChangeNotifier` + `Provider`:

| Провайдер | Что хранит |
|---|---|
| `AuthProvider` | Статус авторизации, текущий пользователь |
| `StocksProvider` | Список акций, загрузка данных, фильтрация |
| `PortfolioProvider` | Виртуальный портфель, баланс, история сделок |
| `TasksProvider` | Список учебных заданий, отметки о выполнении |

### Экраны (`lib/screens/`)

**Авторизация:**
- `auth/login_screen.dart` — экран входа с полями логин/пароль и кнопкой демо-режима

**Главный экран:**
- `home/main_screen.dart` — контейнер с BottomNavigationBar (4 вкладки)
- `home/dashboard_tab.dart` — сводная информация: стоимость портфеля, топ акций
- `home/stocks_tab.dart` — список всех доступных акций с ценами
- `home/portfolio_tab.dart` — позиции пользователя, прибыль/убыток
- `home/tasks_tab.dart` — учебные задания

**Детальный просмотр:**
- `stock/stock_detail_screen.dart` — информация об акции, график цен, прогноз, кнопки покупки/продажи

**Виджеты:**
- `widgets/price_chart.dart` — линейный график цен на fl_chart
- `widgets/buy_sell_dialog.dart` — диалог покупки/продажи с указанием количества

### Сервисы (`lib/services/`)

- `ml_api_service.dart` — HTTP-клиент для обращения к FastAPI backend. Методы: получение прогноза, загрузка истории цен.

### Данные (`lib/data/`)

- `mock_data.dart` — захардкоженные данные для демо-режима. Тикеры Газпром-группы: GAZP, GAZP-p, SIBN, GCHE, MRKZ. Включают цены, объёмы, историю, дивиденды.

## Навигация

```
LoginScreen
    │
    ▼ (успешный вход)
MainScreen
    ├── DashboardTab
    ├── StocksTab ──────► StockDetailScreen
    │                         ├── PriceChart
    │                         └── BuySellDialog
    ├── PortfolioTab
    └── TasksTab
```

Переход между вкладками — через BottomNavigationBar. Переход к деталям акции — через Navigator.push.

## Тема оформления

Светлая тема Material 3 с основным цветом `#1976D2` (синий). Карточки с закруглением 12px и тенью. Кнопки с закруглением 8px.

## Текущее состояние

Приложение полностью работает на мок-данных. Сервис `MlApiService` готов к подключению backend, но в текущей версии данные берутся из `mock_data.dart` и провайдеров.

Для переключения на реальный backend нужно:
1. Запустить FastAPI-сервер
2. Указать URL сервера в `MlApiService`
3. Заменить мок-данные на вызовы API в провайдерах
