# Документация НейроПульс

Это единая точка входа по документации проекта.

## 1. Продукт и стратегия

- `market-analysis-2026-neuropulse.md` — рыночный анализ 2026, unit-экономика, стратегия до 1000 активных.
- `brand-folder-neuropulse.md` — бренд-папка (позиционирование, tone of voice, GTM-рамка).
- `design-system-style-code.md` — визуальная система и дизайн-контракт для дизайнеров/фронтенда.

## 2. Техническая документация

- `architecture.md` — архитектура клиент-серверной системы.
- `backend-api.md` — API backend.
- `flutter-client.md` — структура и поведение Flutter-клиента.
- `ml-model.md` — ML-контур и модель прогнозирования.
- `database-schema.md` — структура данных.
- `deployment.md` — развёртывание.
- `improvements.md` — приоритетные технические улучшения.

## 3. Плановые материалы

- `plans/README.md` — архив планов развития и дорожных сценариев.

## Примечание

Если находите противоречия между документами, приоритет у:
1) `market-analysis-2026-neuropulse.md` (стратегия),
2) `brand-folder-neuropulse.md` (бренд и продуктовая рамка),
3) текущего состояния кода.
